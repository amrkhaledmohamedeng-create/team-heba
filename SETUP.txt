# ربط Dashboard بـ Google Sheets

## 1) أنشئ Google Sheet
افتح Google Sheets وأنشئ ملفًا جديدًا.

## 2) افتح Apps Script
من الشيت:
Extensions → Apps Script

احذف الكود الموجود والصق محتوى `Code.gs`.

## 3) جهز الجداول
من Apps Script شغّل الدالة:
setupSheets

أول مرة سيطلب منك Google صلاحية الوصول إلى الشيت؛ وافق.

سيتم إنشاء:
- Companies
- Areas
- Employees
- Activities

## 4) نشر الـ API
من Apps Script:
Deploy → New deployment
ثم:
- Type: Web app
- Execute as: Me
- Who has access: Anyone

اضغط Deploy وخذ Web app URL.

مثال:
https://script.google.com/macros/s/XXXXXXXX/exec

## 5) وضع الرابط داخل الموقع
في `index.html` ابحث عن:
const API_URL = '';

واجعلها:
const API_URL = 'ضع رابط Web App هنا';

## ملاحظة مهمة
النسخة الحالية تستخدم LocalStorage كنظام احتياطي، والـ API الجاهز في Code.gs هو طبقة Google Sheets.
قبل الاستخدام الفعلي، نربط كل عمليات الإضافة والتعديل والحذف في Dashboard بالـ API، ثم نجعل Google Sheets هو المصدر الأساسي للبيانات.

## الأمان
لا تعتبر كلمة مرور الموظف المخزنة في Google Sheets حماية حقيقية. عند تحويل المشروع للإنتاج، الأفضل استخدام نظام تسجيل دخول حقيقي وصلاحيات من الخادم.
