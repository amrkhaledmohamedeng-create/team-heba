ALEXANDRIA CRM - تسجيل دخول إجباري

- الموقع لا يفتح Dashboard مباشرة.
- عند فتح الموقع بدون جلسة دخول تظهر شاشة تسجيل الدخول فقط.
- admin / 1234 حساب المدير التجريبي.
- إذا لم يكن لدى المستخدم حساب، يضغط «إنشاء حساب جديد».
- بعد إنشاء الحساب يعود لشاشة الدخول، ثم يدخل بالحساب الجديد.
- تسجيل الخروج يعيد المستخدم إلى شاشة الدخول.
- البيانات الحالية للحسابات المحلية تحفظ في المتصفح، وبيانات الموظف الأساسية يمكن مزامنتها إلى Google Sheets عبر Code.gs.
