ALEXANDRIA CRM - النسخة المصححة

1) GitHub:
ارفع index.html و logo.jpg.png إلى Repository الموقع.
يفضل حذف index.html القديم ثم رفع الجديد.

2) Google Apps Script:
ضع Code.gs في Apps Script المرتبط بالـ Google Sheet.
شغل setupSheets مرة واحدة.
ثم Deploy > Manage deployments > Edit > New version > Deploy.
Execute as: Me
Who has access: Anyone

3) رابط الـ Web App المدمج في index.html هو:
https://script.google.com/macros/s/AKfycbyWzp54ChRUptwTkIqcFjqaFa4v8XHLPEoZSA5zBPheBcV9_M183MjZYpnu5s8mVdjz5w/exec

4) تسجيل الدخول:
admin / 1234

5) التسلسل:
الرئيسية > الحي > المنطقة > الشركات > اضغط الشركة > تظهر بيانات الشركة.
بيانات الشركة لا تظهر في قائمة الشركات قبل الضغط عليها.

6) التحكم:
يمكنك إضافة وحذف الأحياء والمناطق، إضافة الشركات والموظفين، وتغيير حالة التواصل.

بعد رفع GitHub اضغط Ctrl+Shift+R.
